# ライブラリ

購入した作品を、表紙つきの一覧で探します。

## 一覧

- ツールバーの「グリッド」「リスト」で表示を切り替えます。
- 作品を押すと、右に詳細が出ます（説明文、ブランド、タグ、クリエイター、ダウンロード・閲覧・起動の操作）。
- 総集編・詰め合わせ・セット商品には、一覧に「総集編」「セット」の印が付き、詳細に「収録作品」が出ます。
  - PCゲームのセット商品は、いつも出ます。**同人・CG などの総集編は、設定の「全般」→「同人・CG などの総集編から収録作品を推定する（実験的）」をオンにしたときだけ**出ます（既定はオフ。精度は保証しません）。
  - 説明文の一覧（セット商品は購入履歴の中身）を、**同じサイトの同じサークルの作品一覧（まだ買っていない作品を含む）** と照らし合わせます。
  - 収録作品ごとに「単独で購入済み」「セットの中身として所持」「単独では未購入」が出ます。**「単独では未購入」は、この総集編で持っているので、単独で買い直す必要はありません。** 押すと持っている作品の詳細へ、作品名の ↗ でストアの作品ページへ移ります。
  - 別の総集編にも収録されていれば「ほかに「…」にも収録」と出ます。
  - 違っていたら、行を指すと出る「選び直す」「外す」で直せます（「自動に戻す」で元に戻ります）。手で直したぶんは、読み取り直しても残ります。
  - サークルの作品一覧は、ストアの公開ページから自動で取り、14 日ごとに取り直します。「一覧を取り直す」ですぐに取り直せます。
  - 単独で持っている作品の詳細には「この作品を収録している総集編・セット（所持）」が出ます。
  - 作品名で検索すると、その作品を収録した総集編・セットも出ます（単独では持っていなくても気づけます）。
  - 説明文を取得した作品が対象です。電子書籍・動画は、手元にある同じサークルの作品だけで照らし合わせます。
- ☆ でお気に入りに入れられます。サイドバーの「★ お気に入り」で、お気に入りだけを表示します。

## 検索

ツールバーの検索欄にキーワードを入れます（`Ctrl+F` または `/` で検索欄へ移動）。

| 項目 | 内容 |
|---|---|
| 検索の対象 | タイトル・ブランド・説明文・作品 ID・人/シリーズ から選べます |
| 正規表現 | 「正規表現」を入れると、正規表現で検索します（大文字・小文字は区別しません）。例: `^魔法.*少女$` |

## 絞り込み（サイドバー）

| 見出し | 内容 |
|---|---|
| 区分 | PC ゲーム・同人・電子書籍・動画など |
| 手元の状態 | ダウンロード済み・インストール済み・未インストール・紐付け候補あり・リンク切れ・未取得（下の表） |
| 購入サイト | DMM / FANZA、DLsite |
| ブランド / サークル | 件数順・名前順で並べ替え、名前や正規表現で絞り込めます |
| 種別 | マンガ・CG/イラスト・ボイス/ASMR・ゲームなど |
| タグ・人 / シリーズ | 名前や正規表現で探して絞り込めます |

複数を選ぶと、それぞれの条件をすべて満たす作品に絞り込みます。

### 手元の状態

| 状態 | 意味 |
|---|---|
| ダウンロード済み | 手元にファイルがある作品、または起動の紐付けが済んでいる作品（DMM GAMES PLAYER と紐付けたゲームなど） |
| └ インストール済み | 起動するファイルの紐付けが済んでいるゲーム・ツール（DMM GAMES PLAYER や導入済みプログラムと紐付けたものを含む） |
| └ 未インストール | ダウンロード済みで、起動するファイルの紐付けがまだのゲーム・ツール |
| └ 紐付け候補あり | PC に入っているプログラムや DMM GAMES PLAYER の中に、紐付けられそうな相手が見つかったゲーム（→ [ゲーム・ツール](games.md#紐付け候補)） |
| └ リンク切れ | 紐付けたソフトをアンインストール・移動して、起動ファイルなどが見つからなくなったゲーム（ある時だけ出ます。→ [ゲーム・ツール](games.md#リンク切れ)） |
| 未取得 | ダウンロード済みでない作品 |

「↻ 最新にする」を押すと、手元のファイルの有無と中身の情報をまとめて確かめ直します（外でファイルを動かした・消したときに）。

## 並べ替え

| 並べ替え | 内容 |
|---|---|
| 購入日順 | 買った日 |
| 発売日順 | 発売日 |
| タイトル順 / ブランド順 | 名前 |
| 利用日順 | ゲーム・ツールを起動した日時か、作品の中身を見た日時の新しい方。使ったことのない作品は後ろに並びます |

隣のボタンで、新しい順・古い順（名前は A→Z / Z→A）を切り替えます。

## 選んで操作する

ツールバーの「ダウンロード ▾」→「選んでダウンロード…」で選択モードになります（`Ctrl+クリック` でもいつでも選べます）。

- カードを押して選び、`Shift+クリック` で範囲を選べます。
- 「選んだ N 件をダウンロード」でまとめてダウンロードします。
- 「ファイルを削除」で、選んだ作品の手元のファイルをごみ箱へ入れます（→ [手元のファイル](local-files.md#削除)）。
- `Esc` で選択モードを終わります。

- 手元の状態（ダウンロード済みなど）で絞り込んでいるときは、ツールバーに「削除」が出ます。
  - 「表示中の N 件のファイルを削除」: 絞り込んだ結果すべて（スクロールで読み込んでいない続きも含む）の手元のファイルを、件数と容量を確かめてからごみ箱へ入れます。
  - 「選んで削除…」: カードを押して選び、「選んだ N 件のファイルを削除」でごみ箱へ入れます。
  - ダウンロード中・処理中の作品は外します。あとで「アプリでダウンロード」から、もう一度ダウンロードできます。
- 「表示中の N 件をダウンロード」も、読み込み済みのページだけでなく、絞り込んだ結果すべてを対象にします。
