# ゲーム・ツール

ゲーム・ツールは、詳細の「インストール・起動」で起動するファイルを紐付けてから、「▶ 起動」で起動します。

## ダウンロードからの流れ

1. ダウンロードが終わると、自動で展開します（設定の「ゲーム」。済んだら zip などを削除するかも選べます）。
2. 展開したフォルダの中身から、インストールが要るかを判定します。

   | 判定 | すること |
   |---|---|
   | インストールせずに動かせそう | 「このフォルダをそのまま使う」または「▶ 起動」（紐付けと起動を一度に） |
   | インストールが必要そう | 「インストーラを実行」→ 自分でインストール → 「導入先のフォルダを選ぶ…」で起動ファイルを紐付け |
   | 追加データ・パッチのよう | 本体の導入先を指定して実行 |
   | 判定できない | 起動するファイルを自分で選ぶ |

   インストーラは起動するだけで、アプリが操作することはありません。

3. 紐付けたら「▶ 起動」で起動します。最後に起動した日時を覚えます（並べ替えの「利用日順」に使います）。

## PC にすでに入っているゲーム

「導入済みプログラムと紐付ける…」で、Windows の「プログラムと機能」に入っているものから選べます。
作品名に近い順に並びますが、同じ名前でも購入元が違うと別物のことがあるので、確かめてから選んでください。

## DMM GAMES PLAYER 専用のゲーム

「DMM GAMES PLAYER専用」のタグが付いた作品は、DMM GAMES PLAYER でインストール・起動します。

1. DMM の公式サイトから DMM GAMES PLAYER を入れ、その中で作品をインストールします。
2. 詳細の「インストール・起動」で、DMM GAMES PLAYER に入っているゲームから選んで紐付けます（フォルダ名が近い順に並びます）。
3. 「▶ 起動」を押すと、DMM GAMES PLAYER に起動を頼みます。

- 専用の作品を持っているのに DMM GAMES PLAYER が入っていないと、サイドバーに警告が出ます。設定の「アカウント」で、入っているか・専用の作品の数・紐付け済みの数を確かめられます。
- アプリは DMM GAMES PLAYER の設定ファイルを読むだけで、書き換えません。ログイン情報も読みません。
- 紐付けた作品は、アプリでファイルを落としていなくても「ダウンロード済み」に数えます。

## リンク切れ

紐付けたあとにソフトをアンインストール・移動すると、起動できなくなります。アプリは次のときに紐付けが生きているかを確かめ、切れていればサイドバーの「└ リンク切れ」に数えます（「インストール済み」からは外れます）。

- 詳細の「インストール・起動」を表示したとき、起動に失敗したとき、起動してしばらくしたとき、同期のあと、「↻ 最新にする」
- 確かめる内容: 紐付けた起動ファイル（無ければインストール先のフォルダ）があるか。DMM GAMES PLAYER の作品は、DMM GAMES PLAYER にそのゲームが入っているか

リンク切れの作品は、詳細に理由が出ます。紐付けを外すか、起動ファイルを選び直してください。入れ直して同じ場所にファイルが戻れば、自動で「インストール済み」に戻ります。紐付けられそうな相手が見つかれば「紐付け候補」も出ます。

## 紐付け候補

まだ紐付けていないゲーム・ツールについて、紐付けられそうな相手を自動で探し、サイドバーの「└ 紐付け候補あり」に数えます（「未インストール」とは分けて数えます）。

| 作品 | 探す場所 |
|---|---|
| DMM GAMES PLAYER 専用 | DMM GAMES PLAYER に入っているゲーム |
| そのほかのゲーム・ツール | Windows の導入済みプログラム |

- 見つかった相手の名前は、詳細の「インストール・起動」に出ます。**紐付けは自動では行いません。** 確かめてから紐付けてください。
- 起動してしばらくしたとき、同期のあと、「↻ 最新にする」、紐付けを外したときに探し直します。
