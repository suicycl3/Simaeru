# ダウンロード

購入した作品のファイルを、アプリの中でダウンロードします。

## ダウンロードする

| 操作 | 内容 |
|---|---|
| 詳細の「アプリでダウンロード」 | その作品をダウンロードします |
| ツールバーの「ダウンロード」 | いま表示している作品をまとめてダウンロードします。必要な容量と空き容量を確認してから始めます |
| 「ダウンロード ▾」→「選んでダウンロード…」 | 作品を選んでダウンロードします |

- すでに手元にある作品は、まとめてダウンロードの対象から外します。
- 分割された作品は、DLsite の分割ダウンロードも含め、各ファイルをキューに登録します。FANZA 動画は選択した画質（既定は最高画質）の全パートを落とします。
  - DLsite の分割ダウンロードは、サイト側がファイル名を返さないため、`作品ID.part1.exe` `作品ID.part2.rar` … の形で保存します。7-Zip が巻をつなげられる並びなので、先頭のファイルから展開できます。
- DRM のある電子書籍・動画は、ファイルを保管するだけです（→ [データとプライバシー](privacy.md#drm-の扱い)）。

### ダウンロードし直す

ダウンロード済みの作品で「アプリでダウンロード」を押すと、落とし直すか確認が出ます。
落とし終えると、手元のファイルと置き換えます（元のファイルはごみ箱へ入ります）。
「MP3 だけ残す」や FLAC 化などで中身を変えた作品を、配布されたままの形に戻すときに使います。ダウンロードのあとの処理は、そのときの設定で行います。

## ダウンロード管理

ステータスバーの「ダウンロード」を押すと開きます。

赤いバッジは「ダウンロード」と「展開・変換」に表示される失敗行の合計です。作品数ではなく処理の行数を数えます。同じファイルの過去の失敗履歴が残っていれば、それも含みます。

### 進み具合

上の欄に、今回まとめて積んだぶんの進み具合を出します。

| 表示 | 内容 |
|---|---|
| n / m 件完了 | 完了した件数 / 全体の件数 |
| 容量 | 受け取った量 / 全体の大きさ（大きさがまだ分からない作品は、作品のファイルサイズで見込みます） |
| 速度・残り | いまの速さと、残りの目安 |

### まとめて操作

| ボタン | 内容 |
|---|---|
| すべて再開 | 一時停止・失敗・中止の行を、まとめて再開します |
| すべて一時停止 | 取得中・待機の行を、まとめて止めます |
| 完了・中止を一覧から消す | 一覧を片付けます（ダウンロードしたファイルは消しません） |

### 行ごとの状態と操作

| 状態 | 意味 | 操作 |
|---|---|---|
| 準備中 | ダウンロード用の URL を取り直しています | — |
| 待機 | 順番を待っています | 一時停止・削除 |
| 取得中 | 落としています（速さを表示） | 一時停止・中止 |
| 一時停止 | 止めています | 続きから（途中から再開）・削除 |
| 失敗 | 3 回やり直しても失敗しました。理由が出ます | 再開・削除 |
| 中止 | 中止しました | やり直す・削除 |
| 完了 | 済みました | 場所を開く |

- 中断したダウンロードは、次に始めるときに途中から続けます（アプリを終了しても続きから取れます）。
- 応答が返ってこないときは、時間を区切って次へ進みます。1 件が止まっても、ほかのダウンロードは止まりません。

「展開・変換」のタブでは、ダウンロードのあとの処理（展開・FLAC 化など）の進み具合と履歴を見られます。

## 保存先とフォルダ構成

設定の「ダウンロード」で変えられます。

| 項目 | 内容 | 既定 |
|---|---|---|
| 保存先 | ダウンロードしたファイルを置くフォルダ | `ドキュメント\Simaeru` |
| フォルダ構成 | 保存先の中の並べ方。`{site}`（購入サイト）`{category}`（区分）`{workType}`（種別）`{maker}`（ブランド）`{title}`（タイトル）`{productId}`（作品 ID）`{year}` `{month}`（購入年・月）を使えます | `{site}/{category}/{maker}/{workType}/[{maker}] {title}` |
| 同時に落とす数 | 1〜8 本 | 1 本 |
| 帯域制限 | すべてのダウンロードの合計の上限 | 制限なし |

保存先やフォルダ構成を変えると、既存のファイルを新しい置き場所へ移すか確認が出ます（→ [手元のファイル](local-files.md#移動)）。

## ダウンロードのあとの処理

作品の種別ごとに、ダウンロードのあとで自動で行う処理を決められます（→ [手元のファイル](local-files.md)、[設定](settings.md)）。

| 種別 | 既定の扱い |
|---|---|
| ゲーム・ツール | 展開して、済んだら zip などを削除 |
| マンガ・CG・ボイス・音楽・動画・小説・その他 | 圧縮したまま保管（種別ごとに「展開して使う」にもできます） |
| ボイス・音楽の WAV | FLAC にする（音はまったく同じで、容量は半分ほど） |
