# はじめに

## 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / 11（64bit） |
| アカウント | DMM / FANZA、DLsite のどちらか（両方でも可） |
| ビルドに必要 | Node.js 20 以降 |
| 外部ツール（任意） | 7-Zip・ffmpeg・NeeView。**同梱していません。** PC に入っていれば使い、無ければ設定画面から配布元（GitHub のリリース）より取得できます |

> このアプリは DMM・DLsite の公式アプリではありません。各サイトの利用規約を守ってご利用ください。

## 入れ方と起動

```bash
npm install
```

`npm install` のあと、`better-sqlite3` が Electron に合わせて自動で再ビルドされます。

| 起動のしかた | 内容 |
|---|---|
| `Simaeru.bat` | ふだんの起動。ビルド済みのものを使い、無ければビルドしてから起動します |
| `Simaeru.bat build` | ソースを更新したあと。作り直してから起動します |
| `Simaeru.bat dev` | 開発モード（画面の変更がすぐ反映されます） |

アプリは多重起動しません。すでに開いているときは、そのウィンドウが前に出ます。

## はじめての設定

### 1. ログインする

1. 左上の「ライブラリ」の右にある ⚙ を押し、「アカウント」を開きます。
2. 使うサイトの「ログイン」を押すと、サイトのログイン画面が別のウィンドウで開きます。そこでログインしてください。
3. ログインできると、状態が「ログイン中」になります。

- ID とパスワードは「ID/PW を保存…」で保存できます。保存すると、次からログイン画面で自動で入力します（**ログインボタンは押しません**）。
  保存した内容は Windows の暗号化で守られ、平文では保存しません。暗号化が使えない環境では保存できません。
- 一般向けの DMM ブックス（dmm.com）は、FANZA（dmm.co.jp）とは別にログインが要ります。一般向けの本を持っているときだけ確認し、未ログインなら警告が出ます。
- ログインしていないサイトがあると、サイドバーの上に警告が出ます。

### 2. 購入履歴を同期する

ツールバーの「購入履歴を同期」を押すと、ログインしているサイトから購入履歴を取り込みます。

- 2 回目からは、新しく買った作品だけを取り込みます。
- 「購入履歴を同期」の ▾ から「全件を取り直す」を選ぶと、すべて取り直します（時間がかかります）。
- 作品の説明文やダウンロードの情報は、ステータスバーの「詳細を自動取得」で裏で少しずつ取得します（速さは選べます）。

### 3. 表示する言語

設定の「全般」で、日本語・English・简体中文から選べます。未設定のときは Windows の表示言語に合わせます。
作品のタイトルや説明文など、サイトから取り込んだ内容は翻訳されません。
