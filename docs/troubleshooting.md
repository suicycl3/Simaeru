# 困ったとき

## ログイン

| 症状 | 対処 |
|---|---|
| ログインしたのに「未ログイン」のまま | 設定の「アカウント」→「ログイン状態を確かめ直す」。直らなければ一度ログアウトしてログインし直してください |
| 「○○ のログインを確認できません」 | 通信がうまくいかず確認できなかった状態です。少し待ってから確かめ直してください |
| 一般向けの DMM ブックスだけ読めない | dmm.com は FANZA とは別のログインです。サイドバーの警告か、設定の「アカウント」からログインしてください |
| 動画だけ取得できない | 「動画だけ未認証です」と出ていたら、そこからログインしてください |

## 同期・ダウンロード

| 症状 | 対処 |
|---|---|
| 新しく買った作品が出ない | 「購入履歴を同期」を押してください。出なければ ▾ の「全件を取り直す」 |
| ダウンロードが「失敗」になる | 行に理由が出ます。ログインが切れていることが多いので、ログインし直して「再開」 |
| 「ダウンロードできるファイルが見つかりませんでした」 | 詳細を開いて「再取得」。DMM GAMES PLAYER 専用の作品や、一般向けの DMM ブックスのログインが要る作品は、理由が出ます |
| 待機のまま進まない | 「すべて再開」を押してください。応答の無いものは時間を区切って次へ進みます |
| DLsite の分割作品でリンクが見つからない | 修正版のアプリを起動し、失敗行を「再開」するか、作品を選んでダウンロードし直してください。分割案内から各ファイルのリンクを取り直します |
| ダウンロードの赤い件数が作品数より多い | 「ダウンロード」と「展開・変換」の失敗行の合計です。同じ作品の複数処理や過去の失敗履歴も含みます |
| 空き容量が足りない | 設定の「ダウンロード」で保存先を別のドライブに変えられます（既存のファイルも移せます） |

## 閲覧・再生

| 症状 | 対処 |
|---|---|
| 1 枚目の画像や、はじめて開く作品がなかなか出ない | 新しいファイルを初めて開くと、Windows の検査で 30 秒ほどかかることがあります。2 回目からは速くなります。失敗したときは「もう一度読み込む」 |
| 画像やボタンが出ない・中身が空 | サイドバーの「↻ 最新にする」で、手元のファイルの情報を確かめ直してください |
| rar / 7z の作品が開けない | 設定の「ツール」で 7-Zip を入れてください |
| DMM の動画をアプリ内で再生できない | 動画の DRM に対応していないため、外部ブラウザで開きます |

## 手元のファイル

| 症状 | 対処 |
|---|---|
| 外で消したファイルが一覧に残る | 「↻ 最新にする」。見つからない行は「一覧から外す」 |
| FLAC 化・MP3 だけ残す・PDF を消すが失敗する | 「ダウンロード管理 → 展開・変換」に理由が出ます。7-Zip / ffmpeg が入っているか、作業フォルダ（%TEMP%）の空き容量を確かめてください |
| 「MP3だけ残す」で「取り出したファイルの数が合いません（…のはずが 0 件）」 | UTF-8 の印がない ZIP を誤った文字コードで展開する問題を修正しました。修正版を起動し「展開・変換」の失敗行からやり直してください。この件数チェックで停止した場合、元のアーカイブは残っています。再発する場合は作品 ID とエラー全文を確認してください |
| ffmpeg が書き込めない | Windows の「フォルダー アクセスの制御」で止められていないか確かめてください |
| 削除できない | ファイルを別のアプリ（ビューアなど）で開いていないか確かめてください |

## ゲーム

| 症状 | 対処 |
|---|---|
| DMM GAMES PLAYER 専用の作品が起動しない | DMM GAMES PLAYER を入れ、その中でインストールしてから、詳細の「インストール・起動」で紐付けてください |
| 紐付け候補が違う | 候補は自動では紐付けません。「導入済みプログラムと紐付ける…」などで正しいものを選んでください |
| 起動時に管理者の確認が出る | ゲーム側の設定によるものです |

## データ

| 症状 | 対処 |
|---|---|
| 起動したら一覧が空になった | データベースが壊れていた可能性があります。`%APPDATA%\simaeru\library.db.corrupt-<日時>` が残っていれば、読める情報は新しいデータベースへ写しています。足りない場合は同期し直してください |
| 別の PC に移したい | アプリを閉じて `%APPDATA%\simaeru` を移してください。ただし保存した ID/パスワードは元の PC・ユーザーでしか復号できないため、入力し直しが要ります |

## 原因が分からないとき

設定の「このアプリについて」→「アプリログ」の**ログを保存…**で、動きの記録を書き出せます。
うまく動かなかった直後に書き出すと、そのときのやり取りが残っています（ID/パスワード・Cookie・ダウンロードURLの署名は含みません）。
ログイン周りだけを見たいときは、隣の「ログイン診断ログ」を使ってください。
