# MCP

AI のアプリ（Claude Code など、MCP に対応したもの）から、Simaeru のライブラリを検索したり操作したりできるようにします。
既定ではオフです。設定の「MCP」→「MCP サーバーを有効にする」でオンにします。

## つなぎ方

オンにすると、設定に「接続先」と「鍵」が出ます。

- 接続先: `http://127.0.0.1:47615/mcp`（ポートは設定で変えられます）
- 鍵: AI のアプリに `Authorization: Bearer <鍵>` として設定します

設定の「AI のアプリでの設定」に、鍵の入った設定がアプリごとに出ます。コピーして使います。

Claude Code（`.mcp.json`）: プロジェクトの `.mcp.json` の `mcpServers` に足します。

```json
{
  "mcpServers": {
    "simaeru": {
      "type": "http",
      "url": "http://127.0.0.1:47615/mcp",
      "headers": { "Authorization": "Bearer <鍵>" }
    }
  }
}
```

Codex（`config.toml`）: `~/.codex/config.toml` に足します。

```toml
[mcp_servers.simaeru]
url = "http://127.0.0.1:47615/mcp"
http_headers = { "Authorization" = "Bearer <鍵>" }
```

鍵が入るので、共有するリポジトリには置かないでください。

Simaeru を起動しているあいだだけ使えます。ウィンドウを閉じても使えるようにしておくには、設定の「全般」で「閉じるボタン（×）を押したとき」を「タスクトレイに常駐する」にします（閉じるときの確認で選んでもかまいません）。

動いているかは、画面下のステータスバーの「● MCP」で分かります（緑: 起動中・赤: 起動できない・灰: 停止中）。押すと、起動・停止・再起動ができます。タスクトレイに常駐しているときは、トレイのアイコンを右クリックした「MCP サーバー」からも同じことができます。ポートがほかのアプリに使われていて起動できなかったときは、ポートを空けてから「起動する」でやり直せます。

## ツール

| ツール | 内容 |
|---|---|
| `search_works` | 作品を探す（文字・タグ・サークル・声優など・区分・種別・お気に入り・使った・手元にあるか・プレイリスト。並べ替えも） |
| `get_work` | 作品の詳細（説明文・スタッフ・すべてのタグ・入っているプレイリスト・手元のファイルの名前と大きさ） |
| `list_tags` / `list_brands` / `list_people` | タグ・サークル（ブランド）・声優や作者などの一覧と作品数 |
| `list_playlists` | プレイリストの一覧 |
| `purchase_stats` | 購入の統計（サイト・種別・月ごと、タグ・サークル・声優・作者の上位）。期間は月（`2026-10`）・日付（`2026-10-07`）・直近の日数（`days: 14`）で絞れます |
| `get_status` | 同期中か、ダウンロードの状況、詳細の自動取得の状況 |
| `set_favorite` / `set_used` | ★お気に入り・♥使った を付ける・外す |
| `add_to_playlist` | プレイリストに作品を足す（名前を指定すると、無ければ作る） |
| `show_work` | アプリの画面で作品の詳細を開く |
| `download_works` | 作品をダウンロードのキューに入れる（サイトから取得します） |
| `start_sync` | 購入履歴の同期を始める（サイトに問い合わせます） |

作品は、検索結果の `id` か、作品 ID（`RJ01234567`・`d_123456` など）で指定します。

## 守っていること

- 待ち受けるのは **この PC の中だけ**（127.0.0.1）です。ほかの PC からはつながりません。
- 鍵を設定したアプリだけが使えます。鍵は設定の「作り直す」で変えられ、前の鍵は使えなくなります。
- ブラウザのページからの呼び出しは断ります。
- ID/パスワード・Cookie・ダウンロードの URL・ライセンスキー・手元のファイルの場所は渡しません。
- ファイルを消す・ログインする、といった操作はできません。
