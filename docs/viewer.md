# 閲覧・再生

手元のファイルは、詳細の「手元のファイル」の上に並ぶボタンから開きます。zip のままでも、展開せずに開けます。

| ボタン | 開くもの |
|---|---|
| ▶ 再生 | ボイスプレイヤー |
| 画像を見る | 画像ビューア |
| PDF | PDF ビューア |
| 動画 | 動画プレイヤー（mp4 / webm / m4v / mov） |
| ○○ を開く | EPUB などの電子書籍を、PC の既定のアプリで開きます |
| 開く / NeeView | ファイルやフォルダを、既定のアプリか NeeView で開きます |

## 画像ビューア

### ページ送り

| 操作 | 内容 |
|---|---|
| クリック | 画面の左右で前・次（綴じ方向に合わせます） |
| ホイール | 下で次のページ（設定で反転できます） |
| ← → | 綴じ方向に合わせて前・次 |
| ↓ / Space / PageDown / Enter | 次 |
| ↑ / PageUp / Backspace | 前 |
| Home / End | 最初 / 最後 |
| S | 見開き |
| T | 一覧（サムネイル） |
| Esc | 閉じる |

- フォルダ（差分・サイズ違いなど）ごとにページを分け、上のメニューで切り替えます。
- 綴じ方向は、マンガは右綴じ、ほかは左綴じが既定です。種別ごとに覚えます。
- 前回のページから続けます。

### 表示の大きさ

| 操作 | 内容 |
|---|---|
| 合わせ方のボタン / F | 全体 → 幅合わせ → 原寸（画像の 1 ピクセルを画面の 1 ピクセルで表示） |
| − / ＋、Ctrl+ホイール、- / + キー | 縮小・拡大（10〜800%） |
| 倍率のボタン / 0 | 倍率を戻す |
| ドラッグ | はみ出しているときに表示位置を動かす |

### 表示とページ送りの設定（⚙ または設定の「画像・CG」）

| 項目 | 内容 |
|---|---|
| ページ送りの速さ | ホイールを回し続けたり、キーを押し続けたりしたときに、ページをめくる間隔（とても速い〜とてもゆっくり） |
| ホイールの向き | 下に回すと次 / 上に回すと次（反転）。「幅合わせ」で縦にスクロールしている間は、スクロールの向きに従います |
| シャープ化（ラプラシアン） | 切・弱・中・強。縮小表示で細い線や文字がぼやけるのを抑えます |
| 拡大の補間方式 | バイキュービック（標準）/ ニアレストネイバー（ドット絵・細かい文字向け。拡大表示のときだけ） |
| PDF の表示 | 縦にスクロール / ページ送り。PDF の上のボタンでも切り替えられます。ページ送りでは、ホイール・`←` `→`・`PageUp` `PageDown`・`Space`（`Shift+Space` で前）・`Home` `End`、◀ ▶ とページ番号の入力でめくります（ボイスプレイヤーの台本欄では、キーは再生の操作のままで、ボタンとホイールでめくります） |
| PDF の見開き | 単ページ / 見開き / 見開き（表紙は単独）と、左綴じ / 右綴じ。PDF の上でも切り替えられます。ページ送りでは組ごとにめくり、右綴じでは右のページから読んで `←` で次へ進みます（◀ ▶ も読む向きに合わせます） |

はじめて開くファイルは、Windows の検査で表示に時間がかかることがあります（読み込み中の表示が出ます）。

## ボイスプレイヤー

- フォルダを「グループ」として並べます。SE あり・なしなどの版は、再生位置を保ったまま切り替えられます。
- 右側に台本（PDF・テキスト）・字幕（lrc / srt / vtt / ass / ssa）・画像を並べて表示します。字幕は再生位置に合わせて進み、行を押すとその位置へ移動します。
- 曲と同じ名前の字幕があると、**台本を見ている間も今の字幕を下に重ねて**出します（下のバーの「字幕」で出す・出さないを切り替え）。
- 台本のタブの右端の ⧉ で、その台本を別ウィンドウに出せます。**再生はそのまま続きます**。
- 台本の PDF は、タブを切り替えて戻っても、読んでいたページ・位置と倍率を保ちます（プレイヤーを開いている間だけで、閉じると 1 ページ目に戻ります）。
- 繰り返し（なし / グループ / 1 曲）、速さ、音量（0〜400%）を選べます。`Space` で再生・一時停止、`←` `→` で 5 秒移動、`↑` `↓` で音量。
- 「音の調整」で、ボイスを目立たせる・音量の均し・低音／高音カット・左右のバランス・左右を混ぜるを変えられます（→ [設定](settings.md#asmrボイス)）。
- 作品ごとに、聴いた位置を覚えます。
- 左上と下のバーに、作品のジャケット（または表紙）を出します。

## ビューア内の検索

PDF と台本のテキストは、中の文字を探せます。🔍 を押すか `Ctrl+F` で検索欄が開きます。

- `Enter` で次、`Shift+Enter` で前、`Esc` で閉じます。
- 全角・半角、大文字・小文字の違いは区別しません。空白や改行もまたいで探します（PDF は文字ごとに区切られていたり、行の途中で改行されていたりするため）。
- PDF は当たった箇所を枠で囲み、そのページへ移ります。文字として埋め込まれていない PDF（ページが画像だけのもの）は探せません。

## 字幕

- 対応している形式: `.lrc` `.srt` `.vtt` `.ass` `.ssa`。`.ass` の装飾の指定は落とし、`\N` は改行として出します。
- **動画**: 動画と同じ名前の字幕（`01_本編.mp4` と `01_本編.srt`、`01_本編.ja.ass` など）があれば、自動で重ねて出します。上のバーで、字幕なし・ほかの字幕に切り替えられます。
- **ボイス**: 上の「ボイスプレイヤー」を参照。

## 別ウィンドウで開く

ビューア・プレイヤーの上の ⧉ で、いま見ているものを別ウィンドウに移せます。

- いくつでも同時に開けます。音声を再生しながら、台本の PDF と画像を横に並べる、といった使い方ができます。
- ボイスプレイヤーを別ウィンドウに移すと、聴いていた位置の続きから再生します。
- 別ウィンドウでも検索・字幕・ページ送りはそのまま使えます。
- 本体のウィンドウを閉じると、別ウィンドウもまとめて閉じます。

## NeeView

[NeeView](https://github.com/neelabo/NeeView)（MIT）が入っていれば、「NeeView」ボタンで開けます。設定の「ツール」から入れられます。

- アプリから入れた NeeView は、**見開き**と**サブフォルダーを読み込む**設定で始まります。
- すでに入っている NeeView は、設定の「ツール」の「見開き・サブフォルダーの設定を入れる」で同じ設定にできます（ほかの設定はそのまま。NeeView を閉じてから）。

## ブラウザで読む・遊ぶ（アプリ内ブラウザ）

詳細の「ビューアで読む」「ブラウザで遊ぶ」などは、アプリの中の窓で開きます。

- ログインしたままなので、ログインし直す必要はありません。
- `F5` 再読み込み、`Alt+←/→` 戻る・進む、`F11` 全画面、`Ctrl+W` 閉じる。
- ボタンの横の ↗ で、PC の既定のブラウザで開くこともできます。
- **ダウンロードした DMM の動画（.dcv）は、「DMM Player で開く」で DMM Player に渡します。** DMM Player が入っていないとボタンは押せません（設定の「アカウント」で確かめられます）。アプリでは復号しません。
- **DMM の動画の「再生（パート n）」「再生（H.264）」は、PC の既定のブラウザで開きます。** アプリ内の窓では DRM のエラーになるためです。「再生（H.264）」は 4K 作品の H.264 版です。
- **DMM の動画のダウンロード**は「アプリでダウンロード」で画質（容量つき）を選んで保管します（複数パートならすべて）。既定の画質は設定の「ダウンロード」→「動画の画質」で決められ、まとめてダウンロードするときもこの既定を使います。再生は DMM プレイヤーなど公式のアプリで行います。
