# Simaeru 機能ドキュメント

DMM / FANZA と DLsite で購入した作品を、1つのアプリで一覧・ダウンロード・閲覧・起動するための Windows アプリの使い方です。

| [ダウンロード](downloads.md) | アプリでダウンロード、まとめてダウンロード、ダウンロード管理、保存先とフォルダ構成 |
| [手元のファイル](local-files.md) | 圧縮のまま保管・展開、FLAC 化、MP3 だけ残す、PDF を消す、削除、移動、取り込み |
| [閲覧・再生](viewer.md) | 画像ビューア、PDF、動画、ボイスプレイヤー、NeeView、アプリ内ブラウザ |
| [ゲーム・ツール](games.md) | インストール・起動、DMM GAMES PLAYER、紐付け候補 |
| [設定](settings.md) | 設定画面の項目の一覧 |
| [データとプライバシー](privacy.md) | データの置き場所、ID/パスワードの扱い、通信先、DRM の扱い |
| [困ったとき](troubleshooting.md) | よくある症状と対処 |
| [開発](development.md) | ビルド、テスト、ソースの構成、翻訳の追加 |
| [仕様](spec/README.md) | 改修の検討向け。構成・IPC・データモデル（テーブル定義）・処理・判定の規則 |

画面の言語は日本語・English・简体中文から選べます（設定の「全般」）。このドキュメントは日本語のみです。
