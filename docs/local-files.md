# 手元のファイル

ダウンロードしたファイル（や取り込んだファイル）は、作品の詳細の「手元のファイル」で管理します。

## 圧縮のまま保管する・展開して使う

| 種別 | 既定 | 理由 |
|---|---|---|
| ゲーム・ツール | 展開して使う（済んだら zip などを削除） | 展開しないと起動できないため |
| マンガ・CG・ボイス・音楽・動画・小説・その他 | 圧縮したまま保管 | 展開しなくてもアプリで閲覧・再生できるため。ファイルが数百〜数千になる作品で保存先を散らかしません |
| DRM のある電子書籍・動画 | 保管だけ | → [データとプライバシー](privacy.md#drm-の扱い) |

- 設定の「ダウンロード」の「ダウンロードのあと（種別ごと）」で、種別ごとに「圧縮したまま保管する」「展開して使う（zip は残す）」「展開して使い、zip は削除する」を選べます。
  展開は、FLAC 化などの作り直しが済んでから行います。
- 作品ごとには、手元のファイルの「展開して使う」（圧縮で持つ作品）・「展開する」（ゲーム・ツール）で展開します。
- 展開したフォルダがあると、閲覧・再生はそちらを使います。要らなくなったら「展開フォルダを削除」で、zip での閲覧に戻せます。

## 容量を減らす

どれも、作り直した zip は作業フォルダで作って検査してから入れ替えます。失敗したときは元のまま残ります。
元のファイルは「ごみ箱へ入れる」「削除する」「残す」から選べます。

### WAV を FLAC にする（ボイス・音楽）

- 音はまったく同じまま、容量が半分ほどになります。変換したあと、元と同じ音か（サンプル数と音声データ）を確かめてから元を処理します。
- 既定で、ダウンロードのあとに自動で行います（設定の「ASMR・ボイス」。WAV の合計が一定以上のときだけ、などを選べます）。
- 作品ごとには「FLAC化」「FLAC化（zipを作り直す）」で行います。
- 32bit 浮動小数点の WAV は FLAC にできないため、そのまま残します。

### MP3 だけ残す（ボイス・音楽）

WAV 版と MP3 版の両方が入っている作品で、MP3 版がある曲の WAV / FLAC だけを削除します。

- SE あり・なし、BGM あり・なし、特典などの版は区別します（SE なしの WAV を、SE ありの MP3 と組にはしません）。
- 組になる MP3 が見つからない WAV / FLAC は残します。
- 日本語のファイル名を持つ Shift_JIS・UTF-8 の ZIP に対応します。UTF-8 の印が付いていない ZIP も判定して展開します。
- 容量は大きく減りますが、元の音質には戻せません（戻すときは「ダウンロードし直す」）。
- 既定では行いません。設定の「ASMR・ボイス」で自動にできます。作品ごとには「MP3だけ残す」。

### 画像と同じ内容の PDF を消す（同人の CG・マンガ）

画像と、同じ内容をまとめた PDF（スマホ向けなど）が両方入っている作品で、PDF を削除します。

- 対象は**同人の CG・イラストとマンガだけ**です。設定の「画像・CG」で、CG とマンガを別々に自動にできます（既定では行いません）。
- 消す PDF の選び方:
  - 名前（フォルダ名を含む）に「スマホ」「PDF版」「タブレット」などがある
  - 名前が画像のフォルダ名と重なる（例: `本編.pdf` と `01_本編/`）
  - いちばん大きい画像フォルダの 1 割以上の大きさがある
  - ただし「おまけ」「設定資料」「説明」など、別の内容らしい名前の PDF は消しません。画像が 10 枚未満の作品や、音声・動画が入っている作品は触りません。
- 作品ごとには「PDFを消す」。確認で、消す PDF の名前を並べます。

## 削除

| 操作 | 内容 |
|---|---|
| 手元のファイルの行の「削除」 | そのファイル（フォルダ）をごみ箱へ入れます |
| 手元のファイルの「すべて削除」 | その作品のファイルをすべてごみ箱へ入れます |
| 選択モードの「ファイルを削除」 | 選んだ作品のファイルをまとめてごみ箱へ入れます |

- 完全には消さず、ごみ箱へ入れます。
- ダウンロード中・展開などの処理中の作品は削除できません。
- インストール先として紐付けているフォルダも消えるときは、確認でお知らせし、紐付けを外します。
- ファイルが残らなければ、あとで「アプリでダウンロード」からもう一度ダウンロードできます。
- ファイルが見つからなくなった行（外で消したなど）は「一覧から外す」で台帳から外せます（ファイルは消しません）。

## 移動

設定の「ダウンロード」で保存先やフォルダ構成を変えると、既存のファイルを新しい置き場所へ移すか確認が出ます。
「今の保存先・フォルダ構成に合わせて並べ直す…」からも行えます。

- 保存先の中のファイルだけを移します（取り込んだ外のファイルは動かしません）。
- 別のドライブへは、複製して中身を照らし合わせてから元を消します（時間がかかります）。
- ダウンロード中のものは移しません。
- 進み具合は「ダウンロード管理 → 展開・変換」で見られます。

## 取り込み

ステータスバーの「取り込み」で、PC にすでにあるファイルを作品と紐付けます。

- 指定したフォルダを読むだけです。ファイルの移動も名前の変更もしません。
- 作品 ID やタイトルで購入履歴と突き合わせ、確度の高いものは自動で紐付けます。ほかは一覧で確認して紐付けます。
  - 作品 ID は全角で書かれていても拾います（`ｄ＿１１６６２６` など）。
  - タイトルは「ダウンロード版」と「DL版」を同じものとして比べます（「完全版」「体験版」は中身が変わるので別の作品のままです）。
  - 名前の末尾に付いた「_DL」「_ver1.07」「_インストなし」は、区切り（空白・_・-）の単位で見て落とします。語の一部の「dl」は壊しません。
  - 【】や () の宣伝文句（「【10,000DL記念】」など）は中身ごと落として比べます。閉じ括弧が無いときも、そこから先は宣伝文句として扱います。
  - 候補は近い順に並びます。ブランド名・サークル名のフォルダのような短い名前だけが引っかかった作品は、候補に出しません。
  - 一覧にはフォルダ名だけでなく、そのフォルダの場所（パス）も出します。`SaveGraphic` のようにどこのものか分からない名前を見分けるためです。
- 同じフォルダにあって候補も同じファイルは、1件にまとめて出します（分割書庫や説明書など、同じ作品の一部とみなします）。「まとめて紐付ける」でフォルダごと一度に紐付きます。
  - 同じフォルダでも別の作品を指すファイルは、取り違えないように分けたまま出します。
- ゲームに同梱されている実行環境（DirectX、VC++ 再頒布可能パッケージ、UCRT など）は作品ではないので、走査から外します。
  - `DirectX` `Runtime` `_CommonRedist` といったフォルダは中を見ません。`directx_Jun2010_redist.exe` `vc_redist.x64.exe` `dxwebsetup.exe` などは、フォルダ分けされていなくても拾いません。

## 最新にする

サイドバーの「↻ 最新にする」で、手元のファイルの有無・中身の情報・紐付け候補をまとめて確かめ直します。
アプリの外でファイルを動かしたり消したりしたときに使います。
