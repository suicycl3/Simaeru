# 設定

サイドバー左上の ⚙ で開きます。

## 全般

| 項目 | 内容 | 既定 |
|---|---|---|
| 表示する言語 | 日本語 / English / 简体中文。切り替えると画面を読み直します | Windows の表示言語（日本語・中国語以外は English） |
| 閲覧・再生したら自動で「使った」にする | ビューア・プレイヤーで中身を開いたとき、公式プレイヤーで見たときに ♥「使った」の印を付けて利用日を残します。オフにすると、カードや詳細の ♡ を押したときだけ印が付きます。ゲームの起動日はこの設定に関係なく残ります（→ [ライブラリ](library.md)） | オン |
| 同人・CG などの総集編から収録作品を推定する（実験的） | 説明文の一覧から収録作品を推定します。**精度は保証しません。** オフのときは、推定した収録作品・結び付き・「総集編」の印を出しません。PCゲームのセット商品など、はっきり分かるものはこの設定に関係なく出します（→ [ライブラリ](library.md)） | オフ |

## アカウント

| 項目 | 内容 |
|---|---|
| 各サイト（DMM / FANZA、DLsite） | ログイン状態、ログイン・ログアウト、ID/PW の保存 |
| DMM 動画・DMM ブックス（一般） | 本体とは別に認証が要るサービスで、未ログインのときに出ます |
| DMM GAMES PLAYER | 入っているか、専用の作品の数と紐付け済みの数。「開く」「確かめ直す」 |
| DMM Player | 入っているか（ダウンロードした動画はこれで開きます）。「確かめ直す」 |
| ログイン状態を確かめ直す | すべてのサイトの状態を確認し直します |

## ダウンロード

| 項目 | 内容 | 既定 |
|---|---|---|
| 保存先 | ダウンロードしたファイルを置くフォルダ | `ドキュメント\Simaeru` |
| フォルダ構成 | 保存先の中の並べ方（トークンは [ダウンロード](downloads.md#保存先とフォルダ構成)） | `{site}/{category}/{maker}/{workType}/[{maker}] {title}` |
| 今の保存先・フォルダ構成に合わせて並べ直す… | 既存のファイルを移します | — |
| 同時に落とす数 | 1〜8 本 | 1 本 |
| 帯域制限 | すべてのダウンロードの合計 | 制限なし |
| 動画の画質 | DMM 動画を「アプリでダウンロード」するときの既定（いちばん高い画質、1080p まで など） | いちばん高い画質 |
| ダウンロードのあと（種別ごと） | マンガ・CG・ボイス・音楽・動画・小説・その他ごとに「圧縮したまま保管する」「展開して使う（zip は残す）」「展開して使い、zip は削除する」 | すべて圧縮したまま |

## ゲーム

| 項目 | 既定 |
|---|---|
| ダウンロードが終わったら自動で展開する | 入 |
| 展開が済んだら、ダウンロードしたファイル（zip など）を削除する | 入 |
| 解凍するだけの exe（自己解凍形式）は、展開して各種処理をしたあと zip に置き換える | 入（exe はごみ箱へ。→ [手元のファイル](local-files.md#解凍するだけの-exe自己解凍書庫)） |

## 画像・CG

| 項目 | 内容 | 既定 |
|---|---|---|
| 画像と同じ内容の PDF を消す | 同人の CG・イラスト / 同人のマンガ・コミック を別々に選べます（→ [手元のファイル](local-files.md#画像と同じ内容の-pdf-を消す同人の-cgマンガ)） | どちらも切 |
| ページ送りの速さ | とても速い・速い・ふつう・ゆっくり・とてもゆっくり | ふつう |
| ホイールの向き | 下で次 / 上で次（反転） | 下で次 |
| シャープ化（ラプラシアン） | 切・弱・中・強 | 切 |
| 拡大の補間方式 | バイキュービック / ニアレストネイバー | バイキュービック |
| PDF の表示 | 縦にスクロール / ページ送り（1 ページずつ） | 縦にスクロール |
| PDF の見開き | 単ページ / 見開き / 見開き（表紙は単独）、左綴じ / 右綴じ | 単ページ・左綴じ |

ビューアの表示の設定は、この PC のこのアプリにだけ保存されます。

## ASMR・ボイス

### 再生の音（ボイスプレイヤーの「音の調整」と同じ）

| 項目 | 内容 | 既定 |
|---|---|---|
| 音の調整 | そのまま / ボイスを目立たせる / ささやき・小さい声を聞き取りやすく / 耳に刺さる音をやわらげる。下の項目を変えると「カスタム」 | そのまま |
| 音量 | 0〜400%。100% を超えると表示が橙色になります | 80% |
| ボイスを目立たせる | 声の帯域（2.5 kHz 付近）を 0〜+12 dB 持ち上げる | 切 |
| 音量の均し | 切 / 弱 / 強。小さい声を持ち上げ、大きい音を抑える | 切 |
| 低音カット / 高音カット | 80・150・250 Hz 以下 / 12・8・5 kHz 以上を抑える | 切 |
| 左右のバランス | 左〜中央〜右（ダブルクリックで中央） | 中央 |
| 左右を混ぜる | モノラルにする（片耳で聞くとき。バイノーラルの立体感はなくなります） | 切 |

音の調整は、この PC のこのアプリにだけ保存されます。100% を超えて上げても割れにくいよう、最後にリミッターを通します。

### ダウンロードのあと

| 項目 | 内容 | 既定 |
|---|---|---|
| WAV を FLAC にする | ダウンロード後に自動で変換します | 入 |
| MP3 版も入っている作品は、WAV / FLAC を削除して MP3 版だけ残す | → [手元のファイル](local-files.md#mp3-だけ残すボイス音楽) | 切 |
| 自動で行う大きさ | WAV があればすべて / WAV の合計が一定以上 | 200 MB 以上 |
| 元のファイル | ごみ箱へ入れる / 削除する / 残す | ごみ箱へ入れる |

## ツール

7-Zip・ffmpeg・NeeView を管理します。

| 操作 | 内容 |
|---|---|
| 自動で入れる… / 最新版を確認 | 配布元（GitHub のリリース）から取得します。取得元・ファイル・大きさを確認してから入れ、配布元のチェックサムと照合します |
| 場所を指定… / 指定を外す | PC に入っているものを使います |
| 入れたものを削除 | アプリが入れたものを削除します |
| 見開き・サブフォルダーの設定を入れる（NeeView） | アプリから入れた NeeView を、見開き・サブフォルダーを読み込む設定にします |

| ツール | 使うところ | ライセンス |
|---|---|---|
| 7-Zip | ゲームの展開、zip 以外（rar / 7z）の閲覧、FLAC 化などのあとの zip の作り直し | LGPL（unRAR 制限あり） |
| ffmpeg | WAV → FLAC 変換と、その検証（LGPL 版を取得） | LGPL |
| NeeView | 漫画・CG 集を外部ビューアで開く | MIT |

版、データの置き場所、使っているソフトウェアのライセンス。

## ステータスバー

| 項目 | 内容 |
|---|---|
| 詳細を自動取得 | 作品の説明文やダウンロードの情報を、裏で少しずつ取得します。速さ（ひかえめ〜最速）を選べます |
| ダウンロード / 取り込み | ダウンロード管理・取り込みを開きます |
| 最終同期 | 最後に同期した日時 |

## このアプリについて

| 項目 | 内容 |
|---|---|
| 版 | アプリの版 |
| データの置き場所 | 台帳・ログイン状態・表紙などを置いているフォルダ |
| アプリログ | 同期・ダウンロード・展開などの動きの記録を、選んだ場所にファイルとして書き出します |
| ログイン診断ログ | ログイン状態の判定だけを取り出した記録です |

どちらの記録にも、ID/パスワード・Cookie・ダウンロードURLの署名は含みません。うまく動かないときの問い合わせに添えられます。
アプリログは `%APPDATA%\simaeru\logs\app.log` に貯まり、2MB を超えると1世代前（`app-1.log`）だけ残して書き直します。
