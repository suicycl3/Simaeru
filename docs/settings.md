# 設定

サイドバー左上の ⚙ で開きます。

## 全般

| 項目 | 内容 | 既定 |
|---|---|---|
| 表示する言語 | 日本語 / English / 简体中文。切り替えると画面を読み直します | Windows の表示言語（日本語・中国語以外は English） |
| 閲覧・再生したら自動で「使った」にする | ビューア・プレイヤーで中身を開いたとき、公式プレイヤーで見たときに ♥「使った」の印を付けて利用日を残します。オフにすると、カードや詳細の ♡ を押したときだけ印が付きます。ゲームの起動日はこの設定に関係なく残ります（→ [ライブラリ](library.md)） | オン |
| すべての作品のタグ情報を取り直す… | すべての作品を「詳細を未取得」に戻し、裏の取得ですぐ取り直します。サイトでジャンルが増えた・直されたときに使います。今あるタグは消さず、取り直したぶんを足します。取り直しが終わるまで、作品は「未取得」として数えられます。進み具合はステータスバーに出ます（数千件なら、設定の速さで数十分〜数時間） | — |
| 同人・CG などの総集編から収録作品を推定する（実験的） | 説明文の一覧から収録作品を推定します。**精度は保証しません。** オフのときは、推定した収録作品・結び付き・「総集編」の印を出しません。PCゲームのセット商品など、はっきり分かるものはこの設定に関係なく出します（→ [ライブラリ](library.md)） | オフ |

## ASMR・ボイス

### 再生の音（ボイスプレイヤーの「音の調整」と同じ）

| 項目 | 内容 | 既定 |
|---|---|---|
| 音の調整 | そのまま / ボイスを目立たせる / ささやき・小さい声を聞き取りやすく / 耳に刺さる音をやわらげる。下の項目を変えると「カスタム」 | そのまま |
| 音量 | 0〜400%。100% を超えると表示が橙色になります | 80% |
| ボイスを目立たせる | 声の帯域（2.5 kHz 付近）を 0〜+12 dB 持ち上げる | 切 |
| 音量の均し | 切 / 弱 / 強。小さい声を持ち上げ、大きい音を抑える | 切 |
| 低音カット / 高音カット | 80・150・250 Hz 以下 / 12・8・5 kHz 以上を抑える | 切 |
| 左右のバランス | 左〜中央〜右（ダブルクリックで中央） | 中央 |
| 左右を混ぜる | モノラルにする（片耳で聞くとき。バイノーラルの立体感はなくなります） | 切 |

音の調整は、この PC のこのアプリにだけ保存されます。100% を超えて上げても割れにくいよう、最後にリミッターを通します。

## 統計・書き出し

購入履歴を期間・サイトごとに集計し、件数の移り変わりを動画・GIF に書き出します。台帳を読むだけで、通信はしません。
「集計」「名寄せ辞典」「動画・GIF」の 3 つのページに分かれています。

**集計**

タグ・声優・作者は、作品の詳細（店舗ページ）を取ってはじめて分かります。
- 詳細を取っていない作品は、タグ・人の集計に入りません（購入数には入ります）。DLsite の作品は、同期の時点でジャンルが分かるのでタグの集計に入ります。
- 未取得の作品があると、ページの上に「タグ取得済み ○ / ○ 件」と「残りを取得」を出します。裏の取得が進むと、集計を取り直します。
- タグの割合と「割合が増えたタグ」は、タグ情報のある作品だけで計算します（未取得の作品で割合が下がらないように）。
- 詳細は取ったが、数える属性タグが 1 つも無い作品（店舗ページが無くなった作品など）の数も出します。

| 項目 | 内容 |
|---|---|
| 期間・サイト | 集計と動画の両方に効きます。期間は月単位で、空ならすべての期間です |
| 概要 | 購入数（サイト別）、種別ごとの件数、月ごとの購入数 |
| タグ（名寄せ後） | 属性のタグの上位 20。× で「数えないタグ」にできます。「ランキング外のタグも表示」で全部のタグを出し、名前で探せます |
| 除外したタグ | × で外したタグ。押すとそのタグを、「すべて戻す」で全部を数えるに戻します |
| 割合が増えたタグ | 期間の終わりまでの 12 か月と、その前の 12 か月で、購入に占める割合が増えたタグ |
| ブランド・サークル / 声優 / 作者・イラスト・シナリオ | 件数の上位 |
| 曜日・時間帯 | 購入時刻の分かる作品だけ（DMM の同人は日付だけなので含みません） |
| 属性ではないとして数えていないタグ | 規則で外したタグの、種類ごとの一覧。押すと「数える」に変えられます |

**タグの数え方**

- 次のタグは数えません。
  - 対象・区分：成人向け・男性向け・オリジナル・旧作、レーベル名（「○○作品」「○○ブランド」）など
  - 販促：セール・クーポン・キャンペーン・コミケ・イベント、西暦の入ったものなど
  - 動作環境：対応 OS・専用・画質（4K など）
  - 評価：「CGがいい」など
  - 形式：マンガ・ADV など
  - 作品ごとの宣伝文句
- 判定には、DMM と DLsite の公式ジャンルの一覧（分類つき）をアプリに同梱して使います。
  - 公式ジャンルは、その分類（シチュエーション・キャラクター・プレイなどは属性、ゲームジャンルは形式、コミケは販促 など）で決めます。
  - DLsite と DMM の同人・PC ゲーム・動画では、公式ジャンルに無い語（新しいセール・宣伝文句・動画の検索語など）を数えません。
  - ただし、公式ジャンルに無くても属性と言える語は数えます。同じ意味の公式ジャンルがあればそちらにまとめます（「なかだし」は中出し、「てこき」は手コキ）。無いものはそのまま数えます（「ノーパン」「女上司」など）。
- 宣伝文句は、語の形（「育成AVG」「…ACT」「…ムービー」など）で判定するほか、DMM の PC ゲームの店舗ページの「ゲームジャンル」欄にあった語も外します。この欄はブランドが作品ごとに自由に書く欄なので、どんな言い回しでも作品の詳細を取ったときに覚えて外します。
- DLsite が言い換えたジャンル（陵辱 ⇔ 屈辱、痴漢 ⇔ 秘密さわさわ など）は、同じジャンルとして数えます。
- DMM と DLsite で同じ意味のタグはまとめて数えます。
  - 区切り（`・` と `/`）や仮名の違いだけのもの
  - 同じ意味で語が違うもの（例: 巨乳 ＝ 巨乳/爆乳、学園もの ＝ 学校/学園）
  - DMM の伏せ字（例: 催●・洗脳 ＝ 催眠・洗脳）
  - 片方のサイトがまとめているもの（例: DMM の「寝取り・寝取られ・NTR」と DLsite の「寝取り」「寝取られ」は 1 つ）
- 1 つの作品に同じ意味のタグが 2 つ付いていても 1 件です。
- 規則の一覧 → [仕様: 統計のタグ](spec/rules.md#統計のタグ)

**名寄せ辞典**

同じ意味のタグをまとめる辞典を、確認・編集できます。グループごとに、代表名（数えるときの名前）と別名、台帳での件数を並べます。

| 操作 | 内容 |
|---|---|
| タグを検索 | 代表名・別名で絞り込みます |
| グループを作る | 新しい代表名でグループを作ります |
| タグを寄せる | グループに別名を足します。台帳にあるタグから選べます。別のグループに入っていたタグは、こちらへ移ります |
| ×（別名） | グループから外します。以後は別々に数えます |
| 名前を変える | 代表名を変えます。元の名前は別名として残り、そのグループに付けた「数えない」の印も引き継ぎます |
| グループを消す | グループを消します。中のタグは別々に数えるようになります |
| 既定の辞典に戻す… | 編集をすべて捨てて、アプリに入っている辞典に戻します |
| 寄せる候補 | 辞典に無い組のうち、DMM と DLsite で書き方の近いもの（片方がもう片方を含む・区切った語が重なる・DMM の伏せ字を埋めると同じ）を並べます。「寄せる」で 1 つのグループにし、「候補から外す」で以後は出しません |

- 区切り（`・` と `/`）や、カタカナ・ひらがなの違いだけのものは、辞典に無くても自動でまとまります。
- 同梱の辞典は、作者の台帳にあったタグを元に作っています。自分の台帳にしか無いタグは、「寄せる候補」から寄せてください。
- 別のグループの代表名になっているタグは寄せられません。先にそのグループを消すか、名前を変えてください。
- 編集した辞典は、集計と動画の両方に効きます。

**動画・GIF**

選んだ対象の上位が月を追って伸び、順位が入れ替わるグラフ（バーチャートレース）です。設定画面でプレビューしてから書き出します。

| 項目 | 選べるもの | 既定 |
|---|---|---|
| 対象 | タグ / ブランド・サークル / 声優 / 作者・イラスト・シナリオ / 種別 | タグ |
| 数え方 | 累計（期間の始めから） / 直近の件数（1〜60 か月） | 累計 |
| 順位 | 上位 5・8・10・12・15・20・30・50・100 位まで、すべて、または範囲を指定（例: 11〜30 位）。上限は、期間の中に 1 件以上ある対象（タグ・ブランドなど）の数。それより多い選択肢は出しません | 上位 10 位まで |
| 1 か月の長さ | 0.05〜1 秒 | 0.15 秒 |
| 進め方 | 購入の多い月ほど長く / どの月も同じ長さ | 購入の多い月ほど長く |
| 書き出し | MP4（H.264） / GIF / WebM（VP9） / アニメーション WebP | MP4 |
| 大きさ | 横（1280×720・1920×1080・640×360）、縦（720×1280・1080×1920・360×640）、正方形（720×720・1080×1080・480×480）、または幅と高さを指定（偶数、90〜3840、画素数は 3840×2160 まで）。GIF・WebP を選ぶと同じ向きの小さい大きさに変わります | 横 1280×720 |

- 期間の中に、選んだ対象（タグ・声優・作者）の情報がまだ無い作品があると、その数（うち期間の終わりの 3 か月の数）を出します。書き出すときは「このまま書き出す」で確かめます。その作品は数えないので、直近の月ほど少なく出ます。
- 「順位を表示」で、棒の左に順位の数字を出します（途中の順位から出すときは、これに関係なく出し、タイトルに範囲を入れます）。
- 「段組み」で、棒を 1〜6 列に分けられます。手で選んだ数はそのとおりに分けます（列が細くなると名前は「…」で省きます）。自動のときは、横長・正方形で 1 列だと行が細くなりすぎる場合に、1 列が細くなりすぎない範囲で列を増やします（縦長は 1 列）。順位は列の上から下へ、左の列から右の列へ並び、棒の長さの基準は全部の列で同じです。
- タイトル・年月・購入数は上の帯に出し、棒の欄とは重ねません（縦長はタイトルを 1 行目、年月と購入数を 2 行目に出します）。
- 本数が多いときは、棒と文字を行の高さに合わせて縮めます。名前が読めないほど細い行では、名前と件数を省いて棒だけを描きます。
- プレビューは書き出しと同じ大きさで描いて、表示だけ縮めています。見たとおりに書き出されます。
- 書き出しには ffmpeg が要ります（[ツール](#ツール)）。保存先は毎回選び、既定は「ダウンロード」です。
- 書き出すのはタイトル・件数・年月とグラフだけで、作品名や画像は入りません。
- ドキュメント・ビデオなどに保存できないときは、Windows の「フォルダー アクセスの制御」で止められていることがあります。別の場所を選んでください。

## ツール

7-Zip・ffmpeg・NeeView を管理します。

| 操作 | 内容 |
|---|---|
| 自動で入れる… / 最新版を確認 | 配布元（GitHub のリリース）から取得します。取得元・ファイル・大きさを確認してから入れ、配布元のチェックサムと照合します |
| 場所を指定… / 指定を外す | PC に入っているものを使います |
| 入れたものを削除 | アプリが入れたものを削除します |
| 見開き・サブフォルダーの設定を入れる（NeeView） | アプリから入れた NeeView を、見開き・サブフォルダーを読み込む設定にします |

| ツール | 使うところ | ライセンス |
|---|---|---|
| 7-Zip | ゲームの展開、zip 以外（rar / 7z）の閲覧、FLAC 化などのあとの zip の作り直し | LGPL（unRAR 制限あり） |
| ffmpeg | WAV → FLAC 変換と、その検証、件数の移り変わりの動画・GIF の書き出し（LGPL 版を取得） | LGPL |
| NeeView | 漫画・CG 集を外部ビューアで開く | MIT |

## このアプリについて

| 項目 | 内容 |
|---|---|
| 版 | アプリの版 |
| 新しい版 | 「新しい版を確認」を押したときだけ、配布元（GitHub）の最新のリリースを問い合わせます。新しい版があれば、リリースのページを開けます。自動では問い合わせません |
| データの置き場所 | 台帳・ログイン状態・表紙などを置いているフォルダ |
| ライセンス | 使っているソフトウェアのライセンスの一覧 |
| アプリログ | 同期・ダウンロード・展開などの動きの記録を、選んだ場所にファイルとして書き出します |
| ログイン診断ログ | ログイン状態の判定だけを取り出した記録です |

どちらの記録にも、ID/パスワード・Cookie・ダウンロードURLの署名は含みません。うまく動かないときの問い合わせに添えられます。
アプリログは `%APPDATA%\simaeru\logs\app.log` に貯まり、2MB を超えると1世代前（`app-1.log`）だけ残して書き直します。

**このアプリを使わなくなったとき**: 「ユーザーデータを削除して終了…」で、データの置き場所のフォルダを丸ごと消してアプリを終了します。
- 消すもの: 台帳（作品の一覧・お気に入り・プレイリスト・紐付け）、設定、保存した ID/パスワード、各サイトのログイン状態、表紙などのキャッシュ、設定の「ツール」から入れた 7-Zip・ffmpeg・NeeView
- 残すもの: ダウンロードした作品のファイル（保存先を画面に出します）と、アプリ本体（Simaeru.exe のあるフォルダ。使わなくなったら手で消してください）
- 確認のチェックを入れるまで押せません。同期・ダウンロード・後処理の途中は断ります。
- フォルダはアプリが終わってから消すので、消し終わるまでの数秒はアプリを開かないでください。
