# データとプライバシー

このアプリは、購入履歴やファイルの情報を**すべてこの PC の中に**保存します。アプリの作者や第三者のサーバーへは何も送りません。

## データの置き場所

| 場所 | 内容 |
|---|---|
| `%APPDATA%\simaeru\library.db` | 購入履歴・手元のファイルの台帳・ダウンロードの履歴・設定（SQLite） |
| `%APPDATA%\simaeru\credentials.dpapi` | 保存した ID/パスワードの控え（暗号化） |
| `%APPDATA%\simaeru\covers\` | 表紙画像のキャッシュ |
| `%APPDATA%\simaeru\tools\` | 設定画面から入れた 7-Zip / ffmpeg / NeeView |
| `%APPDATA%\simaeru\Partitions\` | 各サイトのログインのセッション（Cookie） |
| `%APPDATA%\simaeru\logs\` | アプリの動きの記録（app.log と1世代前。1本 2MB まで） |
| `%TEMP%\Simaeru-cache\` | アーカイブの中の音声・動画を再生するときの一時ファイル（上限あり） |
| `%TEMP%\Simaeru-work\` | 展開・FLAC 変換などの作業フォルダ |
| ダウンロードの保存先 | 既定は `ドキュメント\Simaeru` |

以前の版（MyLibrary）で `%APPDATA%\dmm-library` に置いていたデータは、**初回の起動でフォルダごと `%APPDATA%\simaeru` に引き継ぎます**。中身は動かさず、フォルダの名前を変えるだけです（同じドライブの中の改名なので、途中で終わって片方だけ残ることはありません）。何かの理由で改名できないときは、これまでのフォルダをそのまま使い続けます。

ダウンロードの保存先は、設定済みならそのまま。設定しておらず `ドキュメント\MyLibrary` がある場合は、そのフォルダを使い続けます。

アプリを使わなくなったときは、上のフォルダを削除すれば消えます（ダウンロードしたファイルは保存先に残ります）。

データベースが壊れていたときは、`library.db.corrupt-<日時>` の名前で残してから作り直し、読める情報を写します。

## ID とパスワード

- ログインは各サイトの画面で行います。アプリがログイン情報を受け取ってサイトへ送ることはありません。
- 「ID/PW を保存」したときだけ、Windows の暗号化（DPAPI）で暗号化して保存します。**この PC のこの Windows ユーザーだけ**が復号できます。
  暗号化が使えない環境では保存しません。平文では保存しません。
- 保存した ID/パスワードは、ログイン画面の入力欄へ入れるか、クリップボードへコピーするときだけ使います。**ログインボタンは押しません。**

## 通信先

| 通信先 | 目的 |
|---|---|
| DMM / FANZA（dmm.co.jp・dmm.com とその配信先） | ログイン、購入履歴・作品情報の取得、ダウンロード、表紙 |
| DLsite（dlsite.com とその配信先） | 同上 |
| GitHub（api.github.com・github.com） | 設定の「ツール」で 7-Zip・ffmpeg・NeeView を取得するときだけ |

サイトへは、ログインしたブラウザと同じセッションでアクセスします。作品の説明文などは、間隔を空けて少しずつ取得します（速さは選べます）。

## DRM の扱い

- DMM の電子書籍・動画など **DRM のある作品は、ファイルを保管するだけ**です。アプリで復号することはありません。「開く」で公式のビューア（DMM ブックス・DMM プレイヤー）に渡します。
- 「ビューアで読む」「ストリーミング再生」などは、サイトの公式ビューア・プレイヤーを表示するだけです。
- 動画のストリーミング再生は、公式のプレイヤーをアプリ内の窓で開きます（再生できないときは PC の既定のブラウザで開けます）。
- 総集編の収録作品を探すために、ストアの公開の作品一覧（サークル・ブランドごと）を読みます。送るのはページの取得だけです。

## ファイルの扱い

- ファイルを消す操作は、ごみ箱へ入れます（設定で「削除する」を選んだ変換を除きます）。
- FLAC 化などで作り直すファイルは、作業フォルダで作って検査してから入れ替えます。失敗したときは元のまま残します。
- 取り込みは、指定したフォルダを読むだけです。
