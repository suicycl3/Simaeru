# 判定の規則

規則は `src/shared/contentRules.ts`・`src/shared/storagePolicy.ts`（メインと画面で共通）と、一部 `src/main` にあります。
テストは `tools/test-content-rules.mjs` です。

## 保存のしかた

`decideStorage(product, { hasExecutable })`（`storagePolicy.ts`）

| 条件（上から順に判定） | 結果 |
|---|---|
| `work_type` が `game`・`tool` | `extract`（展開して使う） |
| `category = 'game'` ∧ `work_type` が NULL・`other` | `extract` |
| `work_type` が NULL・`other` ∧ アーカイブの中に実行ファイルがある | `extract` |
| それ以外 | `archive`（圧縮のまま持つ） |

実行ファイルがある: パスが `.exe`・`.msi`・`.bat` で終わる、または `index.html` / `index.htm` がある。

### 種別ごとの扱いの区分

`archiveWorkType(product)`: `work_type` が `manga`・`cg`・`voice`・`music`・`video`・`novel` ならその値、それ以外（NULL・`game`・`tool`・`other`）は `other`。
設定 `post.archiveHandling` をこの区分で引きます。

## PDF を消す対象

`pdfStripType(product)`: `category = 'doujin'` ∧ `work_type` が `cg`・`manga` のとき、その種別。それ以外は NULL。

## 消す PDF

`planPdfStrip(files)` — `files` はアーカイブの一覧またはフォルダの中身（相対パスと大きさ）。

1. 画像（[画像の拡張子](#中身の分類)）が 10 未満、または PDF が無ければ、何も消さない。
2. 音声・動画のファイルが 1 つでもあれば、何も消さない。
3. 画像を親フォルダごとに集計し、最も大きいフォルダの合計を `largest` とする。
4. 画像のフォルダ名（すべての階層）を「名前の核」にする。
5. PDF ごとに、次のどれかに当たれば消す。

   | 条件 | 内容 |
   |---|---|
   | 名前で分かる | 拡張子を除いたパス（フォルダ名を含む）が `スマホ`・`スマートフォン`・`smart phone`・`mobile`・`モバイル`・`携帯`・`タブレット`・`tablet`・`pdf版`・`pdf ver`・`閲覧用` を含む（大文字小文字・空白を問わない） |
   | フォルダ名と重なる | 「別の内容の名前」でない ∧ ファイル名の核が 2 文字以上 ∧ 画像のフォルダ名の核のどれかと、一方が他方を含む |
   | 大きさ | 「別の内容の名前」でない ∧ 大きさが `largest × 0.1` 以上 |

   - 別の内容の名前: パスが `おまけ`・`オマケ`・`特典`・`設定資料`・`資料集`・`あとがき`・`後書き`・`readme`・`read_me`・`説明`・`注意`・`manual`・`マニュアル`・`台本`・`シナリオ`・`script`・`クレジット`・`credit` を含む。
   - 名前の核: NFKC で正規化し小文字にしたうえで、先頭の数字・空白・`._-` と、空白・`._-『』「」【】（）()[]` を除いたもの。

6. 返す値: 消す PDF・その合計・残す PDF・画像の数。

## 消す WAV / FLAC

`planLossyOnly(files)`

- ロスレス: `.wav`・`.flac`・`.aif`・`.aiff`。非可逆: `.mp3`・`.m4a`・`.aac`・`.ogg`・`.opus`。
- ファイルごとに「組のキー」= `版のラベル（形式のラベル MP3・WAV・FLAC・AAC・ハイレゾ を除き、並べ替えて連結）` + `|` + `トラックのキー` を作る。
- 非可逆のファイルと同じ組のキーを持つロスレスのファイルを消す。組が無いロスレスのファイルは残す。

## 版のラベル

`versionTags(folder)` — フォルダのパス（全階層）から、次のラベルを付けます（大文字小文字を問わない）。

| ラベル | 一致する表記 |
|---|---|
| SEなし | `SE`・`効果音` の後に（括弧を挟んでもよい）`なし`・`無し`・`無`・`off`・`ナシ`、または `no SE`・`without SE` |
| SEあり | `SE`・`効果音` の後に `あり`・`有り`・`有`・`on`・`アリ`、または `with SE` |
| BGMなし | `BGM` の後に `なし`・`無し`・`無`・`off`、または `no BGM` |
| BGMあり | `BGM` の後に `あり`・`有り`・`有`・`on`、または `with BGM` |
| 特典 | `特典`・`おまけ`・`オマケ`・`bonus`・`omake`・`extra`・`購入者限定` |
| ハイレゾ | `ハイレゾ`・`hi-res`・`hires`・`96k(hz)`・`192k(hz)`・`24bit` |
| MP3・WAV・FLAC | 英字に挟まれていない `mp3`・`wav`・`flac` |
| AAC | 英字に挟まれていない `m4a`・`aac` |
| バイノーラル | `バイノーラル`・`binaural`・`ダミーヘッド` |

`SEあり` と `SEなし` が両方付くときは、最も深いフォルダ名で決まる方だけを残します。

## トラックのキー

`trackKey(fileName)`

1. ファイル名を NFKC で正規化し、小文字にする。
2. 拡張子（2〜5 文字）を除く。
3. 版を表す語を除く: `SE`・`効果音`・`BGM` + `あり/なし/有り/無し/有/無/on/off`（括弧を含む）、`no/with/without` + `SE/BGM`、括弧で囲んだ `mp3/wav/flac/ハイレゾ/hi-res`。
4. 空白・記号（`_ - . ・ 、 , 。 ~ 〜 ! ！ ? ？ ' " 「」『』()（）[]【】`）を除く。

## 中身の分類

`classifyEntry(relPath)` — 拡張子で分けます（上から順に判定）。

| 分類 | 拡張子 |
|---|---|
| 音声 | `.wav`・`.mp3`・`.flac`・`.m4a`・`.aac`・`.ogg`・`.opus`・`.wma` |
| 字幕 | `.lrc`・`.vtt`・`.srt` |
| 文書（台本） | `.pdf`・`.txt`・`.rtf`・`.html`・`.htm`・`.md` |
| 動画 | `.mp4`・`.webm`・`.mkv`・`.mov`・`.m4v`・`.wmv`・`.avi`・`.mpg`・`.mpeg` |
| 電子書籍 | `.epub`・`.mobi`・`.azw3`・`.fb2`・`.cbz` |
| 台本の画像 | 画像のうち、親フォルダ名が `台本`・`script`・`シナリオ`・`scenario`・`テキスト`・`text`・`セリフ`・`原稿` を含むもの |
| 画像 | `.jpg`・`.jpeg`・`.png`・`.gif`・`.webp`・`.bmp`・`.avif` |

アプリ内で再生するもの: 音声 `.wav`・`.mp3`・`.flac`・`.m4a`・`.aac`・`.ogg`・`.opus`、動画 `.mp4`・`.webm`・`.m4v`・`.mov`。

音声のグループ: 置き場所（アーカイブ・フォルダ）と親フォルダごとに 1 グループ。トラックは名前の自然順（数字を数として比べる）。`特典` のラベルが付いたグループは後ろに並べます。

## アーカイブ

- アーカイブ: 拡張子が `.zip`・`.7z`・`.rar`・`.lzh`・`.lha`・`.tar`・`.cab`。分割は `<名前>.partN.exe|rar`・`<名前>.(7z|zip|rar).NNN` で、1 番目だけをアーカイブとして扱います。
- 展開先のフォルダ名: 拡張子（分割は `.partN.拡張子` まで）を除いた名前。
- zip のエントリ名の文字コード: UTF-8 フラグがあれば UTF-8。無ければ、ASCII だけなら UTF-8、UTF-8 として正しければ UTF-8、それ以外は Shift_JIS。
- 7-Zip による ZIP の一覧・展開: 中央ディレクトリから `legacyCodePage` を判定します。UTF-8 フラグのない名前がすべて UTF-8 として読めれば 65001、読めないものがあれば 932 を指定します。自前で中央ディレクトリを読めない ZIP は従来の 932 に戻します。異なる文字コードが混在する ZIP をファイルごとに切り替える処理ではありません。

`judgeInstall(facts)` — 展開したフォルダの中身から判定します。

| 用語 | 定義 |
|---|---|

| 本体の候補 | `.exe` のうち、名前が `setup`・`install`・`uninst`・`vcredist`・`dxsetup`・`directx`・`dotnet`・`netfx`・`crash`・`report`・`config`・`設定`・`update`・`patch`・`UnityCrashHandler`・`ffmpeg`・`7z`・`unzip` などを含まず、パスがランタイム（`redist`・`runtime` など）でないもの。浅い階層・大きいものを先に並べる |
| ゲームのデータ | 拡張子 `.dat`・`.arc`・`.xp3`・`.pak`・`.pck`・`.wolf`・`.rgssad`・`.rgss2a`・`.rgss3a`・`.pfs`・`.mrg`・`.ypf`・`.int`・`.npa`・`.cpk`・`.assets`・`.bundle`・`.nwa`・`.ogv`・`.fpk`・`.dlc` のファイル、または名前が `data`・`www`・`resources`・`*_data`・`game`・`assets`・`pack`・`archive` のフォルダ |

## 名前の近さ

### タイトルの近さ

`titleSimilarity(a, b)` → 0〜1

1. 両方を NFKC で正規化・小文字にし、空白と `_ - ・ : ： ! ！ ? ？ ~ 〜 「」『』()（）[]【】` を除く。
2. どちらかが空なら 0、同じなら 1。
3. 一方が他方を含むなら `0.5 + 0.5 × 短い長さ ÷ 長い長さ`。
4. それ以外は 2 文字の組の一致率（Dice 係数）。

### 導入済みプログラムの近さ

`min(1, titleSimilarity(作品名, 表示名) + 0.15 × titleSimilarity(ブランド, 発行元))`。紐付け候補にするのは 0.6 以上。

### DMM GAMES PLAYER のゲームの近さ

- `hay` = フォルダ名とゲーム ID を連結し、英数字以外を除いて小文字にしたもの。
- `score = 0.6 × titleSimilarity(作品名, フォルダ名)`
  - ブランド（英数字だけを残して 3 文字以上）が `hay` に含まれれば `+0.4`
  - 作品 ID の `_` より前（3 文字以上）が `hay` に含まれれば `+0.2`
- 上限 1。並びは PC ゲーム（`gameType` が `MAIN` で終わる）を先、その中で近い順。紐付けの画面で「★近い」を付けるのと、紐付け候補にするのは 0.4 以上。

### 取り込みのタイトルの照合

`normalizeTitle`: NFKC・小文字にし、括弧（`【】［］[]（）()`）で囲まれた部分を除き、ひらがなをカタカナにし、文字と数字以外を除く。
パスの各階層（4 文字以上）と作品名を比べ、一致 = `high`、一方が他方を含む = `medium`、省略形で一致 = `medium`。

## 総集編・セット

`src/shared/compilation.ts`・`src/main/sites/catalogParse.ts`

### 総集編らしさ

`isCompilationLike` は、次の両方を満たすときに真です。

- 手がかりがある（`hasCompilationSignal`）: `product_type = 'set'`、タグに `総集編` か `セット商品` を含む、またはタイトルが次のいずれかを含む: `総集編`・`詰め合わせ`・`詰合せ`・`作品集`・`全集`・`まとめセット`・`おまとめ`・`<数字>作品/本` + `セット/パック/収録/詰め`・`セット<数字>作品`・`パック`・`BOX`・`コレクション`・`合本`・`アーカイブス`（英字は大文字・小文字を区別しない）。
- [収録作品の読み取り](#収録作品の読み取り)で 2 つ以上取れる。

### 収録作品の読み取り

`parseCompilationEntries(description)`

1. 見出しの行を探す。見出しは、前後の記号（`■□◆◇●○★☆▼▽【】［］[]<>＜＞《》『』「」=＝-－―`・空白・`:：`）を除くと、`収録作品`・`収録タイトル`・`収録作`・`収録内容`・`作品一覧`・`セット内容`・`同梱作品`・`パック内容`（後ろに `一覧`・`リスト`・`について` が付いてもよい）だけになる行です。
2. 見出しがあれば、その後ろの行を順に読む。
   - 番号つきの行（`01：`・`1.`・`No.3 `・`(4) `・`第5弾：` など）と記号の箇条書き（`・●○◆◇■□▼▽★☆*＊`）は、印を除いた部分をタイトルにします（`listed = true`）。
   - 番号も記号も無い行は、`※`・`■`・`【`・`［`・`＜`・`<`・`注意` で始まれば読むのをやめ、そうでなければ行全体をタイトルにします。行全体が `『…』`・`「…」` か、`【ソフ倫` を含むなら `listed = true`、ほかは `listed = false`。
   - 取れたタイトルが 2 つ以上なら、それを返します。
3. 見出しが無い（または 2 つ未満だった）ときは、説明文全体の番号つきの行を集め、2 つ以上なら返します。

タイトルは次のように整えます: `【ソフ倫…` 以降を除く・末尾の数つきの括弧（`（57ページ）`・`(120枚)` など。単位はページ・P・枚・分・秒・トラック）を除く・先頭の `【初収録】`・`【描き下ろし】` などの印を除く・末尾の `（…発売…）`・`（…年…）` を除く・全体を囲む `『』`・`「」` を除く・前後の記号を除く・空白を 1 つにまとめる。

次のタイトルは除きます。

- [比べる形](#収録作品の照らし合わせ)で 4 文字未満、または 120 文字を超える。
- 枚数・ページ数・時間などの数（`<数字>枚/ページ/P/点/本/分/秒`）、`ファイル`・`形式`・`解像度`・`容量`・`価格`・`円`・`作品収録`・`お得`・`ご参照`・`販売ページ`・`作家`・`作者`・`監修`・`イラスト：`・`シナリオ：`・`CV`・`声優`・`twitter`・`@`・`データ内容`・`のり修正`・`モザイク`・`こちら`・`追加コンテンツ`・`ノリ`・`修正`・`サイズ`・`px`・`制作`・`JPEG`・`PNG`・`PDF版` を含む。
- `枚数`（前に `収録`・`CG`・`画像`・`差分` が付いてもよい）で始まる、`同梱`・`バージョン` で終わる、全体が `【…】` だけ。

### 収録作品の照らし合わせ

`matchCompilationEntries(entries, pool)`。`pool` は `{ key, title, sameMaker }` の配列です。

- 比べる形（`titleCore`）: NFKC で正規化・小文字にし、文字と数字以外（伏せ字の `●○◯*` を含む）を除く。
- 近さ（`entrySimilarity(a, b)` → 0〜1）:
  1. どちらかが空なら 0、同じなら 1。
  2. 短い方が 6 文字以上で、長い方に含まれるなら `0.7 + 0.3 × 短い長さ ÷ 長い長さ`。
  3. それ以外は 2 文字の組の一致率（Dice 係数）。
- `sameMaker` の相手は、近さ 0.72 以上なら候補にします。
- `sameMaker` でない相手は、比べる形が同じか、どちらかが 6 文字以上で他方に含まれる場合だけ近さを計算し、0.92 以上なら候補にします。
- 候補のうち、最も近いものとの差が 0.05 以内のものを、近い順に 3 つまで結び付けます（通常版と廉価版など）。
- `listed = false` で候補が無い収録作品は除き、並び順を 1 から振り直します。

総集編の組み立てでは、作品一覧と手元の同じサークルの作品をすべて `sameMaker = true` で渡します。

## ダウンロード導線

`downloadableLinks(product)`:

- `links` のうち `kind = 'download'`、または `kind = 'page'` で URL が転送ページ（`/proxy/=/transfer_type=download`）のもの。
- `floor_id = 'video'` で複数あるときは、画質を 1 つ選び、その画質のパートすべて（`src/shared/videoQuality.ts`）。
  - 画質の並びは `quality.order`、無ければ画質の印の数（`4k` は最高）。縦の画素数は呼び名の `<数字>p`、無ければ印からの目安。
  - 選び方: 作品ごとの指定 `q:<印>` があればそれ。なければ既定 `best`（最高）か `h:<高さ>`（その高さ以下で最高、無ければ最低）。

導線が無いときの理由（`noLinkReason`）:

| 条件 | 理由 |
|---|---|
| タグに `DMM GAMES PLAYER専用` | DMM GAMES PLAYER でインストールして紐付ける |
| `floor_id = 'book'` ∧ 作品ページが `book.dmm.com` ∧ 取得の失敗がログインによる | 一般向けの DMM ブックスへのログインが必要 |
| 詳細の取得に失敗 | 失敗の内容 |
| それ以外 | ダウンロードできるファイルが見つからない |
