# 仕様

Simaeru の改修を検討・提案するための仕様です。現在の版（データベースの版 27）の動作を記します。

| 文書 | 内容 |
|---|---|
| [構成](architecture.md) | プロセス構成、モジュール、起動と終了、プロセス間通信（IPC）の一覧 |
| [データモデル](data-model.md) | データの置き場所、テーブル定義、値の範囲、JSON の形、設定キー、手元の状態の定義 |
| [処理](processing.md) | 同期、ダウンロード、後処理、中身の一覧、閲覧、インストールと紐付け、ファイル操作、ツールの取得、データベースの開き方、多言語化 |
| [判定の規則](rules.md) | 保存のしかた、消すファイルの選び方、版とトラックの見分け方、名前の近さ など |

利用者向けの説明は [../README.md](../README.md)、ビルドとテストは [../development.md](../development.md) にあります。

## 表記

- 時刻は、特に書かない限り UNIX 時刻のミリ秒（`INTEGER`）です。
- 「ごみ箱へ入れる」は Windows のごみ箱への移動です。
- パスは Windows の表記です。`%APPDATA%` などは環境変数です。
