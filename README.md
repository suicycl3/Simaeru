# Simaeru

[日本語](README.md) | [English](README.en.md) | [简体中文](README.zh-CN.md)

DMM / FANZA と DLsite で購入した作品を **1 か所に集めて、一覧・検索・ダウンロード・閲覧・インストール管理**をする
Windows デスクトップアプリです。

> 非公式のアプリです。DMM・DLsite とは関係ありません。各サイトの利用規約を守り、ご自身が購入した作品の管理にお使いください。

## できること

- **ライブラリ** — 購入履歴を同期して、表紙つきの一覧で探す（区分・種別・ブランド・タグ・人/シリーズ・正規表現・お気に入り・利用日順）
- **ダウンロード** — アプリの中でダウンロード。中断しても続きから、まとめてダウンロード、DLsite の分割ダウンロード、帯域制限、件数・容量・速度・残り時間の表示
- **閲覧・再生** — マンガ・CG・ボイス・動画を **zip のまま** アプリで開く。画像ビューア（見開き・拡大縮小・シャープ化）、台本と字幕を並べるボイスプレイヤー、PDF、動画
- **ファイルの管理** — 種別ごとに「圧縮のまま保管」か「展開して使う」かを選べる。WAV を FLAC に、MP3 だけ残す、画像と同じ内容の PDF を消す、ごみ箱へ削除、保存先の移動、既存ファイルの取り込み
- **ゲーム** — 展開・インストール判定・起動ファイルの紐付けと起動。DMM GAMES PLAYER 専用のゲームの起動、紐付け候補の自動検出
- **ブラウザで読む・遊ぶ** — ログインしたまま、アプリ内の窓で開く
- **画面の言語** — 日本語 / English / 简体中文

## 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / 11（64bit） |
| ビルドに必要 | Node.js 20 以降 |
| 外部ツール（任意） | 7-Zip・ffmpeg・NeeView。**同梱していません。** PC に入っていれば使い、無ければ設定画面から配布元（GitHub のリリース）より取得できます（チェックサムを照合） |

## はじめかた

```bash
npm install
```

| 起動のしかた | 内容 |
|---|---|
| `Simaeru.bat` | ふだんの起動（ビルド済みのものを使う。無ければビルドしてから起動） |
| `Simaeru.bat build` | ソースを更新したあと。作り直してから起動 |
| `Simaeru.bat dev` | 開発モード |

1. サイドバー左上の ⚙ →「アカウント」で、使うサイトにログインします（ログインはサイトの画面で行います）。
2. ツールバーの「購入履歴を同期」で、購入した作品を取り込みます。
3. 作品を選んで「アプリでダウンロード」。済んだら「手元のファイル」から開きます。

## 大事な方針

- **DRM を外しません。** DRM のある電子書籍・動画はファイルを保管し、公式のビューアに渡すだけです。
- **ID/パスワードを平文で保存しません。** 保存するときは Windows の暗号化（DPAPI）を使い、使えない環境では保存しません。ログインボタンを代わりに押すこともしません。
- **データはこの PC の中だけ**に保存します。作者や第三者のサーバーへは何も送りません。
- **ファイルを消すときはごみ箱へ**入れます。作り直すファイルは検査してから入れ替えます。
